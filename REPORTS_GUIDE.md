# Reports Guide

## Overview
The Reports feature provides comprehensive financial analysis with detailed insights into your Uber driving business.

## File Naming Convention

All exported reports follow this naming pattern:
```
UberTracker_[ReportType]_[StartDate]_to_[EndDate]_Generated_[GenerationDate]
```

**Example:**
```
UberTracker_Summary_2026-01-01_to_2026-01-31_Generated_2026-01-22.txt
```

This naming ensures:
- **Easy identification** of report type
- **Clear date range** being analyzed
- **Generation timestamp** for version tracking
- **Unique filenames** preventing overwrites
- **Professional presentation** for record-keeping

## Report Types

### 1. Summary Report (Recommended)
**Includes:** All data with comprehensive analysis

**Sections:**
- Income breakdown with averages
- Expenses categorized (charging vs other)
- Work hours and productivity
- Loan obligations and impact
- **Financial Analysis:**
  - Profitability analysis
  - Productivity metrics
  - Efficiency ratios
  - Loan impact on net profit
  - Key insights and recommendations

**Best For:** Monthly reviews, tax preparation, financial planning

### 2. Income Only Report
**Includes:** Detailed income transactions

**Shows:**
- Each income entry with date and amount
- Total income for period
- Number of income entries
- Average income per entry

**Best For:** Revenue tracking, identifying peak earning days

### 3. Expenses Only Report
**Includes:** All expense transactions

**Shows:**
- Each expense with date, type, and amount
- Charging vs other expense breakdown
- Percentage split of expense types
- Average daily expenses

**Best For:** Cost control, identifying expense patterns

### 4. Loans Only Report
**Includes:** All loan information

**Shows:**
- Each loan with balance and payment progress
- Payment percentage completed
- Total outstanding balance
- Total amount paid

**Best For:** Debt tracking, payment planning

### 5. Hours Only Report
**Includes:** Work hours data

**Shows:**
- Each day worked with hours
- Start and end times (if recorded)
- Total hours in period
- Average hours per day

**Best For:** Schedule analysis, work-life balance tracking

## Report Analysis Explained

### Profitability Analysis
**What it shows:** How much profit you're making

**Key Metrics:**
- **Net Profit Margin:** What % of your income is actual profit
- **Charging Cost %:** How much of income goes to charging
- **Other Expenses %:** Non-charging costs as % of income

**Example Interpretation:**
```
Total Income: $1,000
Charging: $200 (20% of income)
Other: $50 (5% of income)
Net Profit: $750 (75% margin)
```
✓ This is excellent - you keep 75% of gross income

### Productivity Analysis
**What it shows:** How efficiently you convert time to money

**Key Metrics:**
- **Hourly Rate:** Income divided by hours worked
- **Average Hours/Day:** How much you typically work
- **Days Worked:** Total working days in period

**Example Interpretation:**
```
40 hours worked = $1,000 income
Hourly Rate: $25/hr
```
✓ Good rate - above minimum targets

### Efficiency Metrics
**What it shows:** Operating efficiency and cost control

**Key Metrics:**
- **Expense Ratio:** Total expenses as % of income
- **Charging Cost/Hour:** How much charging costs per hour
- **Net Earnings/Hour:** Profit per hour after expenses

**Example Interpretation:**
```
Expense Ratio: 25%
You keep: 75% of gross income
Net Earnings/Hour: $18.75/hr
```
✓ Well controlled expenses

### Loan Impact
**What it shows:** How loans affect your take-home profit

**Key Metrics:**
- **Outstanding Balance:** Total still owed
- **Profit After Loans:** What you keep after payments
- **Months to Payoff:** Time to clear debt at current rate

**Example Interpretation:**
```
Outstanding Balance: $5,000
Monthly Net Profit: $750
Months to Payoff: 6.7 months
```

### Key Insights
**What it shows:** Actionable recommendations

**Symbols:**
- ✓ = Good performance, keep it up
- ! = Needs attention or improvement
- ✗ = Problem area requiring immediate action

**Examples:**
- ✓ "Operating at a profit of $750"
- ! "Hourly rate of $15/hr could be improved"
- ! "Expenses are 60% of income - consider reducing costs"

## Best Practices

### Monthly Review
1. Generate Summary report on last day of month
2. Save with monthly naming: `January_2026_Summary.txt`
3. Review Key Insights section
4. Compare to previous months
5. Adjust strategy based on findings

### Tax Preparation
1. Generate annual Summary report (Jan 1 - Dec 31)
2. Export CSV for your accountant
3. Print report for physical records
4. Keep all monthly reports organized by year

### Performance Tracking
1. Run Weekly Summary reports
2. Track hourly rate trends
3. Monitor expense ratios
4. Identify best performing days/times

### Goal Setting
1. Set target hourly rate (e.g., $25/hr)
2. Set target profit margin (e.g., 70%)
3. Run weekly reports to track progress
4. Adjust working hours/expenses to meet goals

## Tips for Maximum Benefit

### 1. Consistent Data Entry
- Log income daily
- Record expenses immediately
- Track hours accurately
- Update loan payments promptly

**Why:** Accurate reports require accurate data

### 2. Use Date Ranges Strategically
- **Weekly:** Monday to Sunday for quick checks
- **Monthly:** 1st to last day for standard tracking
- **Custom:** Any period for special analysis

### 3. Compare Periods
Generate reports for:
- This month vs last month
- This quarter vs last quarter
- Best month vs worst month

### 4. Export Multiple Formats
- **TXT** for reading
- **CSV** for analysis
- **Print** for filing

### 5. Act on Insights
Don't just generate reports - use them!
- If hourly rate is low → work peak hours
- If expenses are high → find cheaper charging
- If profit margin drops → investigate causes

## Troubleshooting

### "No data for this period"
**Solution:** Check date range, ensure data exists

### "Calculations seem wrong"
**Solution:** Verify all income/expenses are logged correctly

### "Can't open CSV file"
**Solution:** Use Excel, Google Sheets, or Numbers

### "Print layout is off"
**Solution:** Check printer settings, use A4/Letter paper

## Advanced Usage

### Seasonal Analysis
Compare reports across seasons to identify:
- High earning months
- Low expense periods
- Optimal working patterns

### Break-Even Analysis
Use reports to calculate:
- Minimum hours needed for target income
- Maximum expenses allowed for desired profit
- Loan payment capacity

### Efficiency Optimization
Track over time:
- Charging cost per hour (minimize this)
- Hourly rate (maximize this)
- Expense ratio (keep below 30%)
